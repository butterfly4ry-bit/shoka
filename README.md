# 書架 — 蔵書目録

Claude との会話で書いた小説を納めておくための、**オフラインでも読める PWA** です。
古い図書館の閲覧室のような配色（羊皮紙・革・金箔・閲覧灯の緑）で、
題名・あらすじ・シリーズごとに棚を組み、縦書きでも読めます。

- 蔵書はすべて **その端末の localStorage** に保管されます（サーバーには何も送りません）
- いちど開けば **電波がなくても** 起動・閲覧できます（Service Worker）
- ホーム画面に置けば、ふつうのアプリのように立ち上がります
- 小説は **共有URL**（本文をURLの中に圧縮して埋め込む）か **JSON** で持ち運べます

---

## 1. GitHub Pages で公開する

このフォルダの中身をそのまま GitHub リポジトリに置くだけです（ビルド不要）。

```bash
git init && git add -A && git commit -m "書架を建てる"
```

続けて、自分のリポジトリに繋いで push します（`<user>` と `<repo>` は自分のものに）。

```bash
git branch -M main && git remote add origin https://github.com/<user>/<repo>.git && git push -u origin main
```

そのあと GitHub の画面で **Settings → Pages → Source: Deploy from a branch → main / (root)** を選びます。
数十秒で `https://<user>.github.io/<repo>/` に書架が建ちます。

> PWA として端末に入れるには HTTPS が必要ですが、GitHub Pages は最初から HTTPS なのでそのまま入ります。
> リポジトリを Public にすると URL は誰でも開けます。**ただし蔵書は各自の端末の中にしか無い**ので、
> 他人があなたの小説を読むことはできません（共有URLを渡した相手だけが読めます）。

### 端末に置く（インストール）

- iPhone / iPad … Safari で開き、共有 → 「ホーム画面に追加」
- Android … Chrome のメニュー → 「アプリをインストール」
- パソコン … アドレスバー右のインストールアイコン、または画面下の「この書架を端末に置く」

## 2. 使い方

### 収める
`＋ 収蔵する` から、題名・連作名（シリーズ）・第◯話・あらすじ・タグ・本文を入れて納めます。

### 棚の並べ方（連作／叢書）
書架のいちばん上で、棚の組み方を切り替えられます。

- **連作・単巻** … シリーズごと、単発ごとに並べます。
- **叢書（まとまり）** … 編集画面の「叢書（まとまり）」に同じ名前を入れた作品が、連作をまたいで一つの棚にまとまります。
  本編の物語と、そのあとの村の話や、増えていったお祭りの話——本編から離れた後日談も、同じ名前にしておけば揃います。

叢書の中は「**区分**」で見出しに分かれます。`本編` `後日談` `番外編` `外伝` が候補として出ますが、
自分の言葉（`日常` `幕間` など）を入れても構いません。空欄なら「本編」として扱います。
並びは 本編 → 後日談 → 番外編 → 外伝 → 自分で付けた区分 の順。同じ区分の中は「叢書の中での並び順」、
それが空欄なら連作内の順番、それも無ければ収めた順です。

叢書で並べているあいだは、閲覧画面の「前の話／次の話」も**叢書を通した順**で辿ります
（本編の最終話の次が、後日談の一編目になります）。選んだ並べ方は次に開いたときも残ります。

### Claude で書いた小説を取り込む
`書庫` → `貼り付けて取り込む` に、チャットからコピーした文章をそのまま貼ります。受け付ける形は3つ:

1. **素の本文** … 先頭の `# 見出し` を題名として扱います。
   「`##` 見出しごとに別の話として分ける」に印を付ければ、`#` が連作名、`##` ごとが各話になります。
2. **JSON** … `書庫` の「Claude に渡す覚書」をチャットに貼っておくと、Claude がこの形で書き出してくれます。
3. **共有URL** … 下記の共有URLをそのまま貼っても取り込めます。

### 持ち出す・チャットに残す
- **共有URL** … 閲覧画面の `共有URL`、連作の `この連作を共有URLにする`、書庫の `書架まるごとの共有URLを作る`。
  本文そのものを gzip 圧縮して URL の `#` 以降に入れてあります。
  この URL をチャットや自分宛のメモに貼っておけば、**開くだけで書架に戻せます**（別の端末でも同じです）。
  ※ サーバーには送られません。長い作品では URL も長くなるので、その時は JSON 書き出しを併用してください。
- **JSON** … `書庫` → `JSONで保存する`。バックアップ・引っ越し用。共有ダイアログの `JSONを写す` は、
  Claude にそのまま読ませたいときに便利です。

### 書架へ戻る
どの画面にいても、題字の隣の **「← 書架へ」** で読み物の並ぶ書架に戻れます（左上の「書架」の題字も同じ働きです）。
ホーム画面から開いたときはブラウザの戻るボタンが出ないので、こちらをお使いください。

閲覧中は検索欄と「収蔵する」「書庫」を仕舞い、上の帯は題字と「← 書架へ」だけの細いものになります。
iPhone の時計や電池の帯（セーフエリア）にも重ならないようにしてあります。

### 読む
閲覧画面で `縦書き` `小` `大` を切り替えられます。縦書きのときは、ホイールやスワイプで行が送られます。

文字の大きさはこの `小` `大` で変える作りにしてあるため、**端末側のピンチ拡大・ダブルタップ拡大は切ってあります**
（入力欄に触れたときに画面が勝手に寄るのを防ぐためです）。

本文の書き方（どれも任意）:

| 書き方 | 結果 |
| --- | --- |
| 空行 | 段落の区切り |
| `# 見出し` / `## 見出し` | 見出し |
| `---` | 場面転換の罫 |
| `漢字《かんじ》` / `｜語《ルビ》` | ルビ |
| `**強調**` | 強調 |

作品が持てる項目は、題名・連作名・連作内の順番・叢書（まとまり）・区分・叢書の中での並び順・あらすじ・著者・タグ・本文です。

## 3. 中身

| ファイル | 役目 |
| --- | --- |
| `index.html` | 骨組み |
| `styles.css` | 古い図書館の配色（明暗どちらの端末設定にも対応） |
| `app.js` | 書架・目次・閲覧・編集・取り込み・共有URL |
| `sw.js` | オフライン用の Service Worker |
| `manifest.webmanifest` | インストール情報 |
| `icons/` | アイコン |
| `.nojekyll` | GitHub Pages の Jekyll 処理を止める |

外部ライブラリ・CDN・通信は一切ありません。

### 手を入れたあと
`sw.js` の 1 行目の `VERSION`（`shoka-v1`）を `shoka-v2` のように上げてから push すると、
各端末のキャッシュが確実に入れ替わります（上げなくても、次に開いたときには新しくなります）。

### 手元で試す
```bash
python3 -m http.server 8788
```
`http://localhost:8788/` を開きます。

---

## 4. 気をつけること

- 蔵書はブラウザの localStorage にあります。**ブラウザのデータを消すと蔵書も消えます。**
  大切な原稿は、ときどき `JSONで保存する` を押して手元に控えてください。
- 同じ端末でも、Safari と Chrome では別の書架になります。共有URL か JSON で移してください。
